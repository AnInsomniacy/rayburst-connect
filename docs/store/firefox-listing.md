# Rayburst Connect listing

Name: Rayburst Connect

Short description: Send downloads and discovered media to Rayburst, with page sniffing, previews and capture tools.

Redefining the companion browser extension

Rayburst Connect sends browser downloads and discovered media to the Rayburst desktop app. Intercept downloads automatically, send a link from the context menu, or open Sniffer to choose resources from a page.

• Download files, magnet links and torrents with Rayburst.
• Browse media from the current tab or across tabs. Filter resources, copy URLs, preview supported formats and download selections in batches.
• Inspect HLS and DASH streams, choose available video, audio and subtitle tracks, and set recording limits for live sources.
• Use opt-in capture tools for media buffers, playback, screen sharing and WebRTC streams, subject to browser and site support.
• Set download and site rules, switch between light and dark themes, and use the interface in 27 languages.

Requires Rayburst on the same Windows, macOS or Linux computer. Install Rayburst, then enter its Extension API port and secret in the extension settings. These are separate from aria2 RPC settings. The extension can start the installed desktop app when needed.

Download URLs, selected request headers, cookies and captured media are handled locally and passed to Rayburst for the requested task. Cookie and header forwarding can be turned off. Previews and downloads contact the media source you select. There are no ads, analytics or developer-operated processing servers.

DRM-protected media is not supported. Available formats and capture methods depend on the website and browser.
